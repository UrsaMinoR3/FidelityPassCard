# FidelityPassCard

A tiny, free, mobile-first "loyalty card" web app — log a hangout, watch the stamps fill up, just like a coffee-shop rewards card.

## Live page
https://ursaminor3.github.io/FidelityPassCard/

## How it works
- Tap **+ Registrar salida** every time you meet up — it adds one stamp.
- Every 10 stamps completes a card and starts a new one.
- Edit the name shown on the card by tapping it.
- Everything is saved locally on your device (`localStorage`) — no account, no backend, no cost.

## Add it to your home screen (feels like a real app)
**iPhone (Safari):** open the link → Share icon → *Add to Home Screen*.
**Android (Chrome):** open the link → ⋮ menu → *Add to Home screen*.

## Stack
Plain HTML/CSS/JS, no build step, no dependencies. Hosted free on GitHub Pages.
